# AIStory 官网真实样片：素材准备单

状态：等待真实播放器录屏或经确认的剧集媒体。网站现有四张界面截图和 3D 手机动画不是可播放的故事样片；本轮不添加空播放器、不生成替代配音、不承诺已经制作出视频。

## 选片

从当前开发版本中选择一个已经生成、完整可播放、可公开展示的剧集。先实际播放并确认声音、图片、字幕及转场正常，再选 30–60 秒的连续片段。优先包含一个完整叙事小段、清楚的对白或旁白和至少一次真实场景切换，不使用测试报错或占位资产。保留项目仍处开发阶段的说明。

## 录制

直接录制真实播放器，包含内部音频；保持原始画面比例与实际播放速度。不要重新制作角色动作、添加产品没有输出的配音/音效，或把静态图包装成“AI 视频生成”。关闭通知，避开账户资料、密钥和其他私密信息。只裁掉无关的准备/结束时间，不用跳剪掩盖播放问题。

## 交付

- 一份原始录屏（优先 MP4/MOV），及选取的开始/结束时间。
- 样片名称、简短说明、语言、是否有人为编辑；公开标题不要包含内部账户或任务标识。
- 确认该片段的图片和声音允许在官网公开展示。
- 有字幕文件可一并提供；没有时先根据实际音轨逐句核对，不凭截图编造台词。

## 网站接入约束

收到并检查真实素材后才新增样片区：位于 /aistory 首屏之后、创作流程之前，使用原生 video controls / playsinline，关闭 autoplay，preload=none 或 metadata，保留封面、字幕/文字稿和播放失败提示。不能因为新增样片改变 K 构图与轮播行为。

原始录屏和多个转码中间版本留在仓库外。最终只选择一个网络播放版本；建议 H.264 + AAC、保持比例、启用 faststart，并实测画面清晰度与体积后决定存储位置。未确定文件和访问地址之前不创建下载按钮、播放按钮、占位 URL 或额外视频服务。

## 验收

桌面与手机均可主动播放、暂停、拖动和调整音量；不自动出声。检查片段首尾、音画/字幕同步、旋转屏幕、加载失败与无 JavaScript 场景。公开页面明确说明是实际生成作品的播放器录屏及任何人工编辑，不宣称网站能在线生成故事。
